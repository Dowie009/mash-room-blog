8小節のループから脱却し、曲として完成させるための具体的な方法論とワークフローを紹介します。

## 症状チェック

こんな経験、ありませんか？

- [ ] 気づいたら同じ8小節を2時間聴いている
- [ ] フォルダに「新曲_01」〜「新曲_99」がある
- [ ] 完成した曲より未完成の曲が多い
- [ ] 「もうちょっと」が永遠に続く

**3つ以上当てはまったら、この記事が処方箋になります。**

## 処方箋1: 構成を先に決める

ループを作る前に、曲の構成を紙に書き出す：

```
イントロ(8) → Aメロ(16) → Bメロ(8) → サビ(16) → ...
```

**ポイント**: 空のセクションでもいいから、まず箱を作る。

## 処方箋2: 制限時間を設ける

- 1セクションに使う時間: **最大30分**
- 全体の作業時間: **最大3時間/日**

**完璧より完成を優先する**。

## 処方箋3: 「仮」を恐れない

- 仮ドラム: そのまま使う
- 仮メロディ: 80%はそのまま使う
- 仮ミックス: 後で直す（と言って直さない）

## 処方箋4: 書き出してから聴く

DAWの中でループ再生しない。一度書き出して、**別のプレイヤーで通しで聴く**。

| 方法 | 効果 |
|------|------|
| DAW内で聴く | 沼にハマる |
| MP3で聴く | 客観視できる |

## まとめ

曲が完成しないのは才能の問題ではなく、**ワークフローの問題**です。

今日から試してほしいこと：
1. 構成を先に決める
2. タイマーをセットする
3. 「仮」でいいから全セクション埋める
