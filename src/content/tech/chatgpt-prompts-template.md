<h2 id="learning-1">ビジネスメールのプロンプト</h2>

ビジネスメールは頻度が高いからこそ、効率化の効果が大きい領域です。

<div class="pandora-point-box">

### メール作成の基本プロンプト

```
以下の条件でビジネスメールを作成してください。

【宛先】{相手の立場}
【目的】{メールの目的}
【要点】{伝えたいこと}
【トーン】{丁寧/フレンドリー/フォーマル}
```

</div>

### お礼メールのプロンプト

<div class="pandora-example-box">

**コピペ用テンプレート**

```
以下の条件でお礼メールを作成してください。

【宛先】取引先の担当者
【状況】先日の打ち合わせに対するお礼
【追加で伝えたいこと】次回の日程調整
【トーン】丁寧かつ親しみやすく
```

</div>

### お断りメールのプロンプト

<div class="pandora-tip-box">

**ポイント**

断りのメールは特に表現が難しいもの。AIに任せることで、角が立たない文面を素早く作成できます。

</div>

<h2 id="learning-2">企画・提案書のプロンプト</h2>

企画書や提案書の「たたき台」を作るのにAIは最適です。

<div class="pandora-step-flow">

<div class="pandora-step">
<div class="pandora-step-number">1</div>
<div class="pandora-step-content">

### 企画書の構成案を作成

```
以下のテーマで企画書の構成案を作成してください。

【テーマ】{企画のテーマ}
【目的】{達成したいこと}
【ターゲット】{対象者}
【予算感】{大まかな予算}
```

</div>
</div>

<div class="pandora-step">
<div class="pandora-step-number">2</div>
<div class="pandora-step-content">

### 競合分析を依頼

```
{業界}における主要な競合3社について、
以下の観点で比較分析してください。

- 強み・弱み
- 価格帯
- ターゲット層
- 差別化ポイント
```

</div>
</div>

<div class="pandora-step">
<div class="pandora-step-number">3</div>
<div class="pandora-step-content">

### プレゼン資料の骨子作成

```
以下の内容で15分間のプレゼン資料の骨子を作成してください。

【テーマ】{プレゼンのテーマ}
【聴衆】{誰に向けて話すか}
【ゴール】{プレゼン後にどうなってほしいか}
```

</div>

<h2 id="learning-3">文章校正・要約のプロンプト</h2>

既存の文章をブラッシュアップするのもAIの得意分野です。

<div class="pandora-warning-box">

**注意**

機密情報を含む文章をAIに入力する際は、会社のセキュリティポリシーを確認してください。

</div>

### 文章校正のプロンプト

<div class="pandora-example-box">

**コピペ用テンプレート**

```
以下の文章を校正してください。

【チェック項目】
- 誤字脱字
- 文法の間違い
- より適切な表現への修正
- 冗長な部分の削除

【文章】
{校正したい文章}
```

</div>

### 要約のプロンプト

<div class="pandora-conclusion-box">

**シンプルで効果的な要約プロンプト**

```
以下の文章を{文字数}文字以内で要約してください。
重要なポイントを箇条書きで3つ挙げてください。

【文章】
{要約したい文章}
```

</div>
